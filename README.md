# PC Creative Works

Homepage preview for PC Creative Works, a shared retail home for local artisans.

Stack: Vite + React + TypeScript + Tailwind CSS (Lovable-compatible).

```bash
npm install
npm run dev
```

## Before launch
- Stats and maker testimonials in `src/App.tsx` are placeholders; replace with real figures and quotes.
- Images are Unsplash hotlinks; swap for real shop and maker photography.
- Logo is a simple wordmark in `src/components/Logo.tsx`.
